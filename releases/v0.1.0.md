# mssql-mcp v0.1.0

First release: a Model Context Protocol server for Microsoft SQL Server.

## What you can do

- **Explore a database.** Page through schemas, tables, views, columns, keys, indexes, dependencies, stored procedures, functions and storage sizes without writing SQL.
- **Export the schema.** Produce a standalone HTML or JSON map with `mssql-mcp map`, for reviewing an unfamiliar database offline.
- **Read data safely.** Query rows through structured tools with bounded columns, rows and cell sizes; binary and XML columns are projected safely.
- **Write deliberately.** `insert_row`, `update_rows`, `delete_rows` and raw `query` run only after a human approval the server obtains itself. An approval is never a tool argument, so the model cannot answer its own question.

## Safety defaults

- `read` is the default mode and exposes no mutation tool.
- `write` and `both` expose mutations, but refuse them before connecting unless a human approval is obtained.
- On stdio, `--trust-elicitation` opts a trusted host into the native confirmation form, which shows the exact SQL for `query` and the exact values and filters for table mutations.
- The HTTP transport is stateless and never prompts; without `--yolo` its mutations fail closed.
- `--yolo` skips the approval question and is audited. It never widens `read`.
- Audit logs on stderr omit SQL text, values, credentials and result rows.

## Configuration

Use flags or environment variables: `MSSQL_HOST`, `MSSQL_DATABASE`, `MSSQL_AUTH`/`MSSQL_USER`/`MSSQL_PASSWORD`, `MSSQL_PORT`, `MSSQL_MODE`, `MSSQL_MCP_TRANSPORT`, `MSSQL_MCP_HTTP_LISTEN`, `MSSQL_MCP_TOKEN`, `MSSQL_TIMEOUT_SECONDS`, `MSSQL_TRUST_SERVER_CERTIFICATE`, `MSSQL_MCP_YOLO`. Run `mssql-mcp --check-config` to validate without connecting.

Requires Rust 1.88 or newer. Docker and Compose are supported.
